我的题库

上传 Word 或 TXT 文件后，搜题会先检索本机题库。精确匹配且有唯一答案时直接展示题库答案；相似题目会作为参考交给已启用的模型，未匹配时继续由模型作答。

正在加载题库…

支持 .docx、.txt，可多选，单个文件不超过 4 MB。旧版 .doc 请先用 Word 另存为 .docx 或 TXT。题库保存在当前浏览器本机；匹配到的参考条目可能随问题发送给你配置的模型。Word 图片和公式对象不会自动转换为文字，上传后请核对试搜结果。

推荐题库格式与导入说明

每道题用编号或“题目：”开头；有答案的题目加“答案：”，解析可选。也支持含“题目 / 答案 / 解析”表头的 Word 表格。同名文件会追加导入；更新题库前可删除旧文件。没有答案的条目仅用于检索参考。

1. 中国的首都是哪里？
A. 北京
B. 上海
答案：A
解析：北京是中国的首都。

2. 1 + 1 等于多少？
答案：2

LLM 连接

可添加多个服务商：抓题时并行调用，气泡里并列展示各自答案并标记是否一致。只启用一个时，气泡显示与原来一致。

Prompt 模式

默认「答案 + 解析」，可换「自定义」。

快捷键

在 chrome://extensions/shortcuts 中可重新绑定这 4 个命令。Windows / Linux 用 Ctrl，macOS 用 ⌘ Command。

快捷键 作用 何时用
Ctrl+Shift+Q 抓取选区 先在页面选中一段文字（含中文 / 公式 / 代码皆可），按后把选区文本发给 LLM。推荐：网页上能直接选中的题。
Ctrl+Shift+E 抓取可见区域（截图） 整页变暗后拖框选区裁剪，截图发给多模态 LLM。推荐：题目是图片、表格、代码截图、PDF 阅读器视图，或反爬不让选。
Ctrl+Shift+P 抓取整页 DOM 文本 无选区时把整页 innerText 前 6000 字符发给 LLM。推荐：长文章 / 整段题文 / 多选合集。
Ctrl+Shift+H 显示 / 隐藏气泡 答题完成后想收起气泡（不删除内容），再按一次又出现。气泡拖到屏幕任何位置可记忆。

其他触发方式：页面右下角「王」字悬浮按钮（悬停展开 4 个子按钮）、选中文字右键菜单、工具栏图标 popup。
