# 题库功能验证

在仓库根目录运行 `pnpm test` 和 `pnpm check`。无第三方依赖，使用 Node.js 22 或更新版本。

自动化用例覆盖文件编码与 DOCX ZIP 校验、解析、题干/选项匹配、冲突答案、遗漏内容保护、本地存储并发及额度、截图识别回退、模型调用与增量消息。模型 HTTP 和 Chrome API 由测试替身提供，不会访问真实服务商或使用 API Key。

2026-10-04（v0.4.1）：74 项自动化用例通过，全部扩展脚本和 JSON 语法检查通过；其中 15 项覆盖气泡快捷键、隐藏状态保持、快捷键读取与设置入口。另在 Chrome 本地隔离页面中使用生成的测试文件验证了：

- TXT 导入 3 道题，并明确提示其中 1 道没有答案。
- Word 正文和表格导入 2 道题，中文内容和选项可检索。
- 损坏 Word 显示失败并保留已有题库。
- 含图片的 Word 显示遗漏警告，检索结果只能作为参考。
- 不配置 API Key，文字题精确命中直接显示答案、文件名和题号。
- 气泡切换消息可隐藏、恢复原答案节点，内容与来源保持不变；设置页显示快捷键分配状态。

浏览器验证使用独立存储适配层与生成的示例文件，未在用户日常浏览器中安装扩展；因自动化插件未获本地文件访问权限，没有验证系统文件选择器的自动填入操作。正式使用仍应在 `chrome://extensions/` 加载 `src/`，点击上传按钮选择自己的 Word/TXT，核对题库试搜，再配置真实模型验证截图与未命中题目。
